## 一、基础架构演进

### 1.1 Transformer 架构（2017-至今）

#### 核心组件

```
输入 → [词嵌入 + 位置编码] → [N × Decoder层] → [输出头] → 输出
                    ↓
        [多头注意力 + 前馈网络 + 层归一化]
```

**关键创新**：
- **Self-Attention（自注意力）**：全局依赖建模
- **Multi-Head Attention（多头注意力）**：多视角特征提取
- **Position Encoding（位置编码）**：序列位置信息
- **Layer Normalization（层归一化）**：训练稳定性

#### 2026年最新演进

| 技术方向 | 代表工作 | 核心创新 | 发布时间 |
|---------|---------|---------|---------|
| **效率优化** | Step-3.7 Flash | 196B MoE, 11B激活, 400TPS | 2026.05 |
| **规模扩展** | Kimi K3 | 2.8万亿参数, 100万上下文 | 2026.07 |
| **长上下文** | DeepSeek-V4 | 1M tokens, mHC注意力 | 2026.04 |
| **开源生态** | Llama 4 | 原生多模态, 1000万上下文 | 2025.04 |
| **多模态原生** | GPT-5 | 文本/图像/音频/视频融合 | 2025.08 |
