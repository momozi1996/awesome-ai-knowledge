## 二、核心认知：Agent 微调 vs 通用大模型微调（2026 核心差异）
### 2.1 本质区别
**通用大模型微调**
以文本续写、风格对齐、知识灌顶为主，追求话术统一、知识补齐、问答精准，对**结构化行动、工具调用、步骤规划**无要求。

**Agent 微调（2026 专项范式）**
不以“说话好听”为目标，以**行为规范、调用稳定、规划准确、纠错能力提升**为核心目标。微调权重只固化 Agent 行动范式，**保留基座全部通用能力**，实现“通识不丢、执行暴涨”。

### 2.2 2026 行业定论
**Agent 生产落地 95% 场景禁止全参数训练**
- 全参数训练极易造成**灾难性遗忘**；
- 通用知识、多模态理解、基础问答能力退化；
- 训练算力成本极高、迭代慢、无法快速试错；
- 多智能体协作协议、MCP 工具适配极易崩坏。

**轻量化分层微调，是 2026 Agent 落地唯一主流标准**

## 三、三大工业级微调方案选型（LoRA / QLoRA / IA3）
针对不同显存、模型尺寸、业务场景，给出**唯一最优选型标准**，可直接照搬落地。

### 3.1 LoRA 常规轻量化微调（主流首选）
#### 核心原理
冻结基座大模型主干参数，仅训练**低秩矩阵权重**，极小参数量即可习得全新 Agent 行为范式。

#### 适配场景
- 13B / 34B 中等模型商用 Agent
- 需要高精度工具调用、复杂任务规划
- 需要保留极强基座通用能力
- 单卡 24G+ 显存设备

#### 优劣势
- 优势：效果稳定、泛化强、几乎不遗忘、权重体积小
- 劣势：无法适配极低显存设备

### 3.2 QLoRA 4/8 比特量化微调（低显存神器）
#### 核心原理
基座模型量化压缩为 4bit/8bit 精度，仅 LoRA 权重浮点训练，**显存极致压榨、精度可控损失**。

#### 适配场景
- 7B 端侧轻量化 Agent
- 个人开发者、单卡低显存（6G–16G）
- 快速迭代、场景试错、数据小规模微调

#### 优劣势
- 优势：极低显存、开箱即用、训练速度快
- 劣势：超高精度复杂规划略有损失，不适合 70B+ 高阶工业底座

### 3.3 IA3 注入式微调（极简能力补强）
#### 核心原理
通过向量注入扰动模型注意力与激活层，参数量比 LoRA 更小，几乎**零资源消耗**。

#### 适配场景
- 仅做简单工具调用微调
- 小场景能力补强、风格对齐
- DPO 偏好对齐辅助微调

#### 优劣势
- 优势：极致轻量、极速收敛
- 劣势：无法承载复杂长链条 Agent 训练

### 3.4 2026 模型尺寸微调选型总规则
- **7B 端侧 Agent**：QLoRA 4bit（唯一性价比方案）
- **13B 商用 Agent**：LoRA 为主、QLoRA 备选
- **34B 复杂 Agent / 多智能体**：标准 LoRA 最优
- **70B+ 工业底座**：分层 LoRA + 分布式微调

## 四、Agent 专属分层微调策略（核心壁垒）
普通微调全部层统一训练，是**Agent 微调崩坏的最大元凶**。
2026 工业级标准：**Agent 分层差异化微调**，不同网络层承担不同能力，单独调控。

### 4.1 网络层能力拆分
1. **底层嵌入层**：负责语义、通识、语言能力 —— **冻结禁止训练**
2. **中层注意力层**：负责任务理解、意图识别 —— **轻微微调**
3. **高层推理层**：负责任务拆解、逻辑推理、DAG 规划 —— **重点微调**
4. **输出预测层**：负责结构化工具调用、反思输出 —— **全力微调**

### 4.2 分层微调核心价值
- 彻底杜绝**通识遗忘**
- 最大化强化 Agent 决策与执行能力
- 工具调用准确率、长任务完成率大幅提升
- 微调后模型**更聪明、更稳、不智障**

## 五、Agent 微调四阶段工业流水线（可直接复用）
承接上一章训练体系，微调完整落地流程：

### 阶段一：结构化 SFT 微调（行为打底）
使用标准化 Agent 六段式数据微调，固化：
- MCP 工具调用格式
- 基础任务拆解范式
- 标准执行步骤输出

### 阶段二：长链条轨迹微调（能力拔高）
使用 5–15 步长轨迹数据微调，解锁：
- 复杂任务自主规划
- 子任务依赖判断
- 动态重规划能力

### 阶段三：负样本纠错微调（去幻觉、降错误）
注入错误样本、失败轨迹、幻觉案例，让模型学会：
- 规避无效调用
- 拒绝虚假推理
- 自检步骤漏洞

### 阶段四：DPO 偏好对齐微调（体验商用化）
优质轨迹 vs 劣质轨迹对比训练，统一：
- 最优执行路径
- 严谨输出风格
- 高效任务逻辑

## 六、2026 最优超参数配置（Agent 专用、开箱即用）
### 6.1 7B QLoRA 低显存配置
```
batch_size = 2
grad_accumulation = 8
learning_rate = 2e-4
lora_rank = 16
lora_alpha = 32
quant = 4bit
epoch = 3–5
warmup_steps = 100
```
适配：个人本地单卡、端侧 Agent、轻量化工具智能体

### 6.2 13B/34B LoRA 商用配置
```
batch_size = 4
grad_accumulation = 4
learning_rate = 1e-4
lora_rank = 32
lora_alpha = 64
epoch = 2–3
warmup_ratio = 0.1
weight_decay = 0.01
```
适配：中小企业商用、多步骤自动化、知识库 Agent

### 6.3 微调通用铁律
- **Agent 训练 epoch 严禁过高**：超过 5 极易过拟合、执行僵化
- 学习率**宁小勿大**：大学习率直接冲毁行为范式
- 必须开启**学习率预热+余弦衰减**

## 七、微调后权重融合与部署方案
### 7.1 三种上线模式
1. **LoRA 动态加载（调试首选）**
   基座 + LoRA 权重动态挂载，随时切换场景权重，适合迭代调试。

2. **权重合并固化（生产首选）**
   LoRA 与基座合并为单一完整模型，推理速度无损耗、部署简单，商用标准方案。

3. **多 LoRA 路由融合（2026 高阶）**
   不同场景微调多个 LoRA，运行时根据任务类型**动态路由加载**，实现一个基座适配办公、代码、科研、数据分析多场景。

### 7.2 微调后必须做的两件事
- **能力回归评测**：校验通识能力未退化、工具调用准确率提升
- **幻觉率抽检**：复杂任务测试，确认纠错能力生效

## 八、微调高频翻车避坑指南（2026 实战总结）
1. **混用通用文本数据微调 Agent**
   后果：话术变流畅、执行彻底崩坏，工具调用错乱。

2. **不分层全局微调**
   后果：灾难性遗忘，模型只会任务、不会正常对话。

3. **Epoch 过高、过拟合**
   后果：只会训练集样本，真实场景完全无法泛化。

4. **缺少负样本微调**
   后果：正确率高、容错极低，线上稍微异常直接幻觉。

5. **直接全参数训练**
   后果：算力爆炸、迭代成本极高、无法持续更新。

## 九、高频 SEO FAQ（新手友好、高收录）
**Q1：微调一定会让模型遗忘原有能力吗？**
不会。使用分层 LoRA/QLoRA 微调、冻结底层通识层，**只会增强 Agent 能力，几乎无损原有能力**。全参数训练才会大概率遗忘。

**Q2：7B 小模型微调后可以商用吗？**
完全可以。2026 轻量化微调体系成熟，7B 微调后可稳定胜任自动化办公、知识库问答、简单工具流水线、轻量化多智能体任务，满足绝大多数中小企业场景。

**Q3：Agent 微调需要多少数据？**
无需百万级。**2W–20W 高质量结构化 Agent 样本**，即可完成极佳微调效果，质量远大于数量。

**Q4：微调和 RAG 是什么关系？**
RAG 解决**知识缺失、实时信息**问题；
微调解决**行为习惯、决策规划、工具调用范式**问题；
二者互补，高端商用 Agent 必须「微调 + RAG + 反思」三位一体。

**Q5：多智能体系统需要单独微调吗？**
需要。必须使用**A2A 协作专属数据微调**，否则会出现角色越权、沟通混乱、任务推诿等协作 bug。
